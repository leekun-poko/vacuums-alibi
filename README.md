A tiny, dependency-free Python program that writes one deadpan line in which a robot vacuum explains why it missed a corner: the dust unionised, elected a crumb, and served it a restraining order — and it does not cross picket lines. The output is a single line of UTF-8 text, byte-for-byte deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` to /output in the grader, or to $MAKEFUN_OUTPUT_DIR outside a container.
